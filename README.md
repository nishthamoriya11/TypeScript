# TypeScript Practice Projects

A collection of beginner-friendly TypeScript programs created to practise programming fundamentals, understand core concepts, and improve problem-solving skills.

This repository contains two projects covering basic TypeScript operations, data types, conditional statements, and different types of loops.

## Projects Overview

### 1. Basic TypeScript Programs

**Folder:** `project_1/`

This project contains 20 basic TypeScript programs designed to build a strong foundation in programming.

**Topics Covered**
- Variables and data types
- Output using `console.log()`
- Arithmetic operators and mathematical calculations
- String and number conversion
- The `typeof` operator and the `any` type
- Swapping two numbers
- Conditional statements using `if`, `else if`, and `else`
- Grade calculation and voting eligibility
- Electricity bill and salary calculation
- Discount calculation
- Temperature conversion
- Converting minutes into hours and remaining minutes
- Displaying a message on a webpage using HTML and TypeScript

**Files**
- `project_1.ts` — Contains the TypeScript programs.
- `project_1.html` — Provides the HTML page used for the webpage output example.

### 2. TypeScript Loop Programs

**Folder:** `project_2_loop/`

This project focuses on loops and their applications in solving repetitive programming problems.

**Topics Covered**

**While Loop**
- Printing numbers in ascending and descending order
- Sum of the first N natural numbers
- Multiplication table
- Counting digits in a number

**Do-While Loop**
- Printing numbers from 1 to 20
- Printing even and odd numbers
- Reversing a number
- Calculating the sum of digits

**For Loop**
- Printing numbers from 1 to 50
- Calculating squares and cubes
- Finding the factorial of a number
- Generating the Fibonacci series

**Mixed Loop Programs**
- Checking prime numbers
- Checking palindrome numbers
- Checking Armstrong numbers
- Printing star patterns using nested loops
- Counting attempts in a number-guessing program

**File**
- `loop.ts` — Contains the loop-based TypeScript programs.

## Technologies Used

- **TypeScript** — For writing and practising typed JavaScript programs.
- **HTML** — For displaying output on a webpage.
- **Node.js** — For running compiled JavaScript programs.
- **Visual Studio Code** — For writing, editing, and managing code.
- **Git and GitHub** — For version control and project hosting.
